# usa-jingu-saidaimon

Prefectural record identifies four-legged gate. Conservation report identifies gabled roof, front/rear karahafu and flanking wickets, cypress bark covering.12x9.1x5.8m model including eaves is estimated; mapped footprint anchors center and112.4deg long axis.
