# Terrain tile bake

From the repository root, with Python, NumPy and Pillow installed:

```sh
python3 tools/bake-terrain-materials.py
python3 tools/bake-terrain-materials.py --check --preview output/terrain-materials
```

`terrain-art.json` contains the seed and normalized stone fracture polylines.
The original `stone-tone.png` and its provenance remain authoring inputs.
The bake combines that tone source with independent metric relief; brightness
does not define height. Grass uses overlapping warped tufts, sand uses shallow
isotropic aggregates, and snow uses soft settled variation. These are artistic
signals, not measured physical properties.

`terrain-tiles.rgba8` is exactly 262,144 bytes: four 128×128, interleaved linear
data tiles in sand, grass, rock, snow order (atlas layers 2–5). R is centered
tone, GB encode `0.5 + dH/dUV / 4`, and A is perceptual roughness. Height uses
metres; wrapped central derivatives use a 128/8 multiplier. The shader applies
`4 / period_m` and its existing artistic strength. Do not import this as sRGB
or interpret alpha as transparency.

The bake verifies source identity, output bounds, unclipped gradients, mean
tone, wrap-neighbor continuity and quantized derivative integrability.
`--check` also verifies exact generated bytes and source hashes. Runtime loads
only the raw base tiles and retains the atlas's existing eight-level mip filter.
All other layers, semantic sharing, palette and shader behavior stay in their
existing consumers.

## Construction finishes

```sh
python3 tools/bake-construction-materials.py
python3 tools/bake-construction-materials.py --check --preview output/construction-materials
```

The construction bake authors sixteen default semantic finishes on atlas layers
23–38: brick, stone, plaster, timber, clay tile, slate, panel, metal, siding,
shingle, flat roofing, thatch, namako, limestone, marble and earthen plaster.
Ten explicit variants occupy layers 45–54: corrugated metal (roofs and
cladding), flat plain clay tiles, uncoursed rubble, painted vertical boards,
wood shingles, woven organic panels, corrugated cement sheets, turf, plain glazed
ceramic and patterned glazed ceramic. Variant 1 is selected by the building's finish specification,
never inferred from its colour. Standing seam, rounded tiles, ashlar, bare timber,
horizontal siding and composition shingles keep their distinct default art.
Variant 2 on metal roofs or panel walls shares the corrugated profile with a
0.9 minimum roughness for matte sheet surfaces; it does not infer chemical
composition from a grey roof or assert that the sheet contains asbestos.
Variant 3 on metal roofs reuses the rounded tile profile for tile-stamped
coated sheets. It suppresses ceramic firing variation and changes base roughness
from 0.67 to 0.51 while retaining excess filtered variance. No extra atlas layer
is needed; the semantic covering remains metal. The developer-submitted
[Puri Mas Atambua built-house record](https://sikumbang.tapera.go.id/lokasi-perumahan/ATB0420012020T001)
identifies coloured metal tiles separately from its block walls; the photographed
profile supports this variant without treating every tile-shaped roof as clay.

Variant 2 on timber walls selects a separate woven organic panel, with shallow
alternating ribbon crossings and calm broad fibre variation. The roughly 70 mm
weave is illustrative; it does not assert a measured species-specific pattern.

Catalog `CEMENT_SHEET_ROOF`, `TURF_ROOF` and `BITUMEN_ROOF` compile to
variants 1, 2 and 3 of the shared `ROOF` material. The compiler owns this encoding
and rejects a conflicting explicit variant. Cement uses wider mineral corrugations
and high roughness; turf uses soft sod/clump relief without thatch courses or grass
geometry. Bitumen shares the flat-roof membrane tile on source-compatible pitches.
These coverings do not borrow slate or metal material identities. The two new
128² layers cost 174,760 GPU bytes including mips and use the existing single fetch.

Catalog `AZULEJO_WALL` and `AZULEJO_PATTERN_WALL` select variants 1 and 2
of the ceramic-wall material, keeping ordinary namako unchanged. The former
uses regional RGB as solid glaze; the latter uses it as pattern **ink**, mixed
with an off-white ceramic ground. Pattern R stores linear ink coverage rather
than centered tone, so mip filtering preserves the two-pigment mean. GB and A
retain their gradient and roughness meanings. The original two-by-two geometric
repeat uses approximately 143 mm square tiles; shallow 2 mm joints and glaze
roughness are illustrative. The [Lisbon municipal factory inventory](https://hemerotecadigital.cm-lisboa.pt/obras/LisboaRevM/N5_6/N5_6_master/N5_6.pdf)
records 13–15 cm tiles, and the [official Porto guide](https://visitporto.travel/storage/01HRWD2GGEDZY75FC3ZZW3TAYR.pdf)
shows both plain turquoise glaze and blue-on-white domestic façades. No historic
panel or photographed pixels are copied. Each surface retains one atlas fetch;
the two layers cost 174,760 GPU bytes including mips.

The bake takes wrapped metric height derivatives at 512², then area-integrates
slopes into each 128² tile. Differentiating the reduced height instead would
suppress narrow corrugations before normal mip filtering. The 1,703,936-byte
base asset uses the same linear RGBA encoding and eight runtime mip levels as terrain. The 55-layer GPU atlas
uses 4,805,900 bytes including mips. Variants add 873,800 bytes; geometry,
texture fetch count and the 12-byte packed vertex size are unchanged. Packed
normal vertices carry the variant in two previously unused alpha bits. Baking
replaces construction synthesis at startup. `--check` verifies bytes, generator
hash, signal bounds, mean pigment,
wrapped cuts, source derivative integrability, quantized filtered slopes and
finish variation. An analytic 76 mm corrugation guards physical slope retention.

Construction and earthen repeats cover 4 m; veined marble retains its generic
8 m consumer. Construction slope gain is 1; marble and earthen retain the
generic shader's 1.5 gain. R is pigment variation or explicit pattern coverage, never baked illumination.
Broad lime/trowel variation, per-piece firing or stone coloration, sparse
chips and directional grain supplement structural joints. A varies with the
finish, and the existing mip filter carries unresolved slope energy into
roughness. Regional RGB remains authoritative, including landmark pigments.

All construction fields are original procedural art under the repository
license; no reference-game pixels or external texture assets are bundled.
The source manifest links the primary art-direction references. Adobe's
[Bell Island breakdown](https://www.adobe.com/products/substance3d/magazine/the-creation-of-bell-island.html)
informs the hierarchy of feature scales and selective defects. Valve's
[art guide](https://help.steampowered.com/en/faqs/view/0688-7692-4D5A-1935)
informs restrained values and readable quiet areas. These principles guide
our generators; they do not imply reproduction of proprietary Zelda assets.
Review channel maps and two-repeat previews, then inspect the materials in
the production renderer under different sun angles and viewing distances.
